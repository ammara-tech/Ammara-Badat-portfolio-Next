For spam protection (stopping fake or junk messages sent by bots), I chose a honeypot and a rate limit instead of a CAPTCHA (the "I'm not a robot" puzzle), so real visitors never have to solve anything. The honeypot is a hidden form field that people can't see but bots fill in, so any message with that field filled in is thrown away, and so is any message sent in under three seconds. The rate limit is a rule inside my Supabase database that allows only three messages from the same email or visitor every ten minutes, and RLS (database rules for who can see each row) means visitors can only send messages, while only my account can read them. The worst layout bug I fixed was on phones: the Home page could be scrolled sideways, because one long line in my code card made the whole top section wider than the screen. I fixed it by making the column fit the screen, letting the text wrap onto a new line and making the code text smaller on phones, and I also made my grey and red text brighter so it is easier to read (it now passes WCAG AA, the web standard for readable text).
