I made a projects table in Supabase (an online database) that stores each project's title, summary, links, image, tags and display order, and my Projects page now reads from this table instead of from text typed into the code. I turned on Row Level Security, or RLS (rules inside the database that decide who can see or change each row), with four policies: anyone can read the projects, but only my own account can add, edit or delete them on my private /admin page. I also turned off sign-ups, so nobody else can create an account. To prove it works, I opened my site in a private (incognito) window where I was not signed in, and tried to read, add, edit and delete projects from the browser console (a tool for running code inside the browser). Reading worked and showed all 7 projects, but adding was blocked with error 42501 (the database saying "you are not allowed"), and editing and deleting changed nothing.
